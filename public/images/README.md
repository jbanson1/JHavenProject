# Photos

The site currently uses free stock photos from [Unsplash](https://unsplash.com) (Unsplash License:
free for commercial use, no attribution required). Replace them with real property photos as soon as
you have them: either overwrite the files keeping the same names, or change the paths in
`site.config.ts` → `photos`. Set a path to `null` to show a drawn placeholder instead.
